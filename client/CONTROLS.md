# 星夢 Online（Godot）— 滑鼠移動操作

## 地面移動

| 操作 | 行為 |
| --- | --- |
| 左鍵點一下地面 | 一般尋路，角色走到點擊的位置後停止 |
| 左鍵按住地面、未達 **1 秒** | 沿用原本長按跟隨滑鼠位置的方式；放開後保留最後的尋路目的地 |
| 左鍵在地面持續按住 **滿 1 秒** | 進入鎖定持續走路模式；游標放大約 35%，旁邊持續顯示 **「🔒 自動走路 ON／右鍵停止」** |
| 鎖定後放開左鍵 | 不會中斷；角色繼續朝游標方向尋路，不必按著滑鼠 |
| 鎖定時再左鍵點一下**地面** | 解除鎖定，恢復一般點擊地面單次尋路 |
| **右鍵** | 解除鎖定並停止原本的地面尋路。右鍵點其他玩家時，**原本的玩家右鍵選單仍會開啟** |

### 互動優先順序

- 右鍵是非消費式輸入：`Player._input` 只停止自己控制的地面移動，
  不呼叫 `set_input_as_handled()`，其他玩家的 `_input_event`
  仍可開啟原本的選單，既有技能右鍵取消流程也保持。
- 點擊 NPC、怪物、掉落物、其他玩家（含 PvP 目標）時，
  先解除自動走路並停止原先尋路，再由原本的實體點擊處理
  對話、追擊、撿物等行為；不會攔截或吞掉原事件。
- 點擊可接收滑鼠事件的 UI 控制項時，也會先停走並保留
  視窗／按鈕自己的事件；一般地面點擊仍走原本的一次尋路。
- 技能／攻擊／NPC／撿物／玩家專用游標優先於自動走路動畫。
  開啟 UI 視窗時不顯示自動走路圖示，避免擋住 UI。
- 換圖、死亡、Server 位置校正（含機甲下車）、技能目標選取時，
  會清除鎖定。不可把前一張地圖的尋路結果用在新地圖。
- 地形由既有 `Blocking.dat` 與 Server 驗證；鎖定模式不開新
  封包種類，也不放寬穿牆、距離、移動速度限制。

## 實作與測試位置

- `scripts/mouse_autorun_state.gd`：純狀態機，判定 1 秒、
  短點擊／長按／再次地面點擊／取消。
- `player.gd`：既有路徑尋找、輸入與地圖移動，外加長按鎖定、
  右鍵停走、互動時取消。卡住重試有 0.4 秒節流，避免每幀 A*。
- `scripts/cursor_manager.gd` +
  `ui/cursor/C_AUTOWALK.spr.png`：320×32 透明 PNG，10 影格、每格 32×32，
  參考原始 `C_NORMAL.spr.*.png` 的白藍箭頭與金色裝飾。
  `CursorManager` 使用 `AtlasTexture` 注入 `autorun` 動畫，
  只在鎖定時放大動畫游標約 35%，旁邊顯示深色金框、
  白字的「🔒 自動走路 ON／右鍵停止」固定狀態標籤，
  不再依賴較不顯眼的雙箭頭動畫判斷狀態。
  標籤會跟著滑鼠、靠近視窗邊界自動避讓，並設為
  `MOUSE_FILTER_IGNORE`，不攔截任何點擊。
  NPC／攻擊／技能／UI 專用游標優先時隱藏標籤、
  恢復原本游標尺寸，不影響 legacy cursor hover 優先權。
  PNG 仍是**原有 320×32**，不要把顯示尺寸當成素材尺寸。
- `tests/mouse_autorun_regression.gd`：Godot 原生行為測試。
- `tests/player_map_movement_regression.gd`：換圖／下機甲校正。
- `../tests/test_mouse_autorun_contract.py`：原始碼與 Runner 接線防護，
  不取代 Godot 真正執行。
- `../tests/run_protocol_checks.ps1`：Windows 完整驗證入口。

### 注意

程式與測試已接線，但只有**實際 Godot headless 和遊戲內滑鼠互動**
驗證成功後，才能確認游標與對話框／玩家選單沒有互相阻擋。
