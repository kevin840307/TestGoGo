--魔裝機甲操作說明書(NQ019_B)

function start()
    AddItem(10428)
	dia_01()
end

function dia_01()    
	Ask("h歡迎使用魔裝機甲操作說明書，請選擇閣下要翻查的項目。","魔裝機甲合體流程","魔裝機甲合體配備","魔裝機甲操作手冊","還是不看了","reply_01")
end

function reply_01()
	ans = GetChoice()
	if ans==0 then
		dia_02()
	elseif ans==1 then
		dia_03()
	elseif ans==2 then
		dia_04()
	end
	QuestEnd()
end

function dia_02()
	Ask("h魔裝機甲合體流程\n\n1合體隊員須先組隊。\n\n2隊員必須在機甲上裝上一套合體魔裝卡和一顆貝塔晶石，才能參與合體。(各隊員裝的合\n  體魔裝卡可以不同，但必須是一整套3張)\n\n3隊員必須駕駛機甲後，戰鬥一斷時間把機甲達至「怒」的狀況，隊長才能使用合體晶片合\n  體。\n\n4『合體晶片』有人數限制，不參加合體的隊員會自動脫離隊伍。\n\n5合體後，裝備的貝塔晶石便會消失，怒的能量亦會消耗。","觀看魔裝機甲說明書目錄","還是不看了","reply_02")
end
function reply_02()
	ans = GetChoice()
	if ans==0 then
		dia_01()
	end
	QuestEnd()
end

function dia_03()
	Ask("h「魔裝機甲合體配備」\n\n1合體魔裝卡：是機甲強化卡外的特殊強化卡，每套共有三張卡，分別為：星之魔裝卡、月\n之魔裝卡和日之魔裝卡，隊長機甲的合體魔裝卡會影響合體機甲的種類。\n\n2貝塔晶石：共有4種，分別代表不同屬性和能力，分別是：貝塔火晶、貝塔水晶、貝塔土\n晶、貝塔風晶。每個隊員的機甲必須裝上一顆貝塔晶石才能合體。\n\n3合體晶片：利用貝塔晶石合成而來，隊長使用時，若其他條件配合，便能合體。\n\n4合體晶片成份：\n合體微晶片=貝塔火晶+貝塔風晶+貝塔土晶。\n合體原晶片=貝塔火晶+貝塔風晶+貝塔土晶+貝塔水晶。\n合體限晶片=兩顆合體原晶片。\n合體極晶片=三顆合體原晶片。\n\n5合體晶片人數限制：\n合體微晶片：隊長、狙擊手、道具師，三人，無能力加乘。\n合體原晶片：隊長、狙擊手、道具師、魔靈師，三至四人，小量能力加乘。\n合體限晶片：隊長、狙擊手、道具師、魔靈師、狙擊手，三至五人，一般能力加乘。\n合體極晶片：隊長、狙擊手、道具師、魔靈師、狙擊手、魔靈師，三至六人，強大能力加乘。","觀看魔裝機甲說明書目錄","還是不看了","reply_02")
end

function dia_04()
	Ask("h「魔裝機甲操作手冊」\n\n1隊長可替合體機甲改名。\n\n2合體後不同隊員會跟據不同的位置，作出不同的操作：\n  隊長(必須由隊長擔任):負責移動及攻擊。\n  隊長的行動會決定合體機甲的行動與一般攻擊，但不能使用角色的技能和物品。\n  狙擊手：負責使用攻擊技能。\n  狙擊手能使用自己的攻擊技能，但不能使用其他技能和物品。\n  魔靈師：負責使用回復技能。\n  魔靈師能使用自己的回復技能，但不能使用其他技能和物品。\n  道具師：負責使用不同的物品，但不能使用技能。\n  只有道具師能使用攻擊或回復等不同的物品，以應付戰鬥時的不同需要。\n\n3合體後，只有隊長能和NPC交談，其他隊員若點選NPC將不會有任何反應。必須由隊長解散後  才能自由活動。\n\n4合體後，只有隊長能拾取地上的物品，拾取的物品會隨機給物品欄仍有空間的隊員。\n\n5每一種造型的魔裝機甲，都會有其獨立的必殺技。當合體後，角色的技能欄內會因應魔裝\n  機甲種類而增加必殺技，合體機甲不論是使用技能或一般攻擊，它的必殺技能量亦會上升\n  ，當必殺技能量全滿時，隊員必須同時使用必殺技，才能使必殺技達至最佳同步率效果，對目\n  標造成致命攻擊。","觀看魔裝機甲說明書目錄","還是不看了","reply_02")
end
